# 微影製程：疊加偏移（Overlay）與對齊異常筆記

- 目標：深入理解黃光微影（Lithography）製程中的關鍵缺陷模式——疊加偏移（Overlay Error）與對齊異常（Alignment Abnormality）。建立從 MES 生產現象、NPI 測試指標、到晶圓圖（Wafer Map）特徵的完整對讀 SOP，以便為機器學習模型的缺陷分類輸出提供具備說服力的物理意義解釋。

## 1. 微影製程與疊加偏移（Overlay）核心物理概念

-   1. 什麼是疊加偏移（Overlay）？
    - 半導體晶圓是由數十層電路（如鰭式架構 Fin、閘極 Gate、金屬層 Metal）層層堆疊而成。
        - 物理定義：疊加偏移是指「當前製程層（Current Layer）」與「前一層基準層（Reference Layer）」之間的幾何對齊誤差。
        - 量化指標：測試資料或 Log 中常見的 OVERLAY_X 與 OVERLAY_Y，代表兩層電路在 X 軸與 Y 軸方向上的位移偏差量，通常以奈米（nm）為單位。如果數值超出製程規格（Spec Limit），將導致電路斷路、短路或高頻頻寬嚴重衰減。
-   2. 什麼是對齊警告（Alignment Warning）？
    - 在微影曝光前，機台（Scanner/Stepper）會透過光學鏡頭捕捉晶圓上的對對齊記號（Alignment Marks）。當晶圓表面存在嚴重的缺陷、平整度不佳、或雷射訊號異常時，機台 Log 會拋出 對齊警告（Alignment Warning / Target Acquisition Failure），這通常是晶圓邊緣幾何變形或曝光重疊失敗的前兆。

## 2. 缺陷對照 SOP 筆記：微影疊加偏移

- 當您的 WaferResNetClassifier 判定晶圓圖存在特定的空間缺陷分佈時，請對照以下根因分析模型：

|               評估維度                | 產線實務與數據特徵分析對照                                                                                                                                                                                                                                                     |
| :-----------------------------------: | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|             缺陷類型名稱              | 疊加偏移（Overlay Error）/ 微影對齊失效                                                                                                                                                                                                                                        |
|  晶圓圖空間特徵(Wafer Map Topology)   | 1. 環狀缺陷（Edge Ring）：不良點群聚於晶圓的最外圍邊緣。<br>2. 旋轉擴散（Rotational Distortion）：點位誤差向量隨著半徑增大而呈現同心圓向外扭曲。                                                                                                                               |
| MES 現場生產現象(MES Common Symptoms) | 1. 黃光機台拋出對齊警告（Alignment Warning）或手動超馳（Manual Override）日誌。<br>2. 曝光能量或焦距（Focus Recipe）在特定批次有微小波動。                                                                                                                                     |
|   NPI 電性測試指標(NPI CTQ Metrics)   | 1. 關鍵尺寸變異：CD_LINEWIDTH 超規或不均勻。<br>2. 電性量測：高頻頻寬（Bandwidth）受限、特定接腳漏電流（leakage_current）超標。                                                                                                                                                |
| 根因與物理成因(Physical Root Causes)  | 1. 晶圓邊緣應力（Stress Warpage）：晶圓邊緣因熱應力不均產生微幅翹曲，導致機台感測器在邊緣區域抓不到對齊馬克，引發「環形缺陷」。<br>2. 卡夾/載台污染（Chuck Particle）：曝光機台的晶圓座（Chuck）邊緣有微小粒子污染，導致晶圓放上去時邊緣局部懸空傾斜，產生焦距異常與疊加偏移。 |
