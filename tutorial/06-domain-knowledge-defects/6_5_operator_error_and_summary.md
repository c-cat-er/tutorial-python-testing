# 操作錯誤與摘要筆記

- 目標：
    - 識別操作員錯誤指紋：掌握人為超馳（Manual Override）與批量異常在 MES 與數據管道中的行為特徵。
    - 建構缺陷特徵總摘要：將 6.1 至 6.5 的所有缺陷模式進行結構化橫向對齊，提煉出資料庫查詢的關鍵特徵欄位，為第七章的主流程控制（main.py）提供判讀基準。

1. 人為操作疏失 (Operator Error / Manual Override)
    - 數據庫指紋與機台 Log 特徵
        - 日誌指紋：MES 或機台系統日誌中密集出現 Manual_Override_Activated、Set_Value_Changed 或 Bypass_Safety_Protocol。
        - 空間拓撲特徵：在晶圓圖（Wafer Map）上呈現整批次（Lot-based）突發性、非幾何對稱的批量異常，例如同一個 Lot 內的 25 片晶圓在完全相同的扇形區域集體電性失敗。
        - 電性指標（CTQ）：呈現跨模組的單一指標超規，通常與製程物理極限無關，而是設定值偏離。
    - 底層物理機制
        - 物理成因：線上手動操作員未按照標準作業程序（SOP），在機台執行量測或加工時，手動更改了跳載設定（Recipe Parameters）或硬體補償值；或是傳送帶（FOUP）未卡緊導致晶圓在物理卡槽中發生非對稱局部擦傷。
    - Python 系統自動化行動 (Action)
        - 人為風險標記：當系統解析 Log 發現存在 Manual_Override 時間戳記，且隨後預測良率異常時，資料庫的 alert_status 會被強制覆寫為 HUMAN_RISK，並凍結該操作員帳號當下處理的所有 Lot。

## 2. 第六章：半導體缺陷模式與數據庫篩選主鍵大摘要表

- 將 6.1 至 6.5 的完整領域知識，提煉為第七章軟體 Pipeline 系統能直接讀取的結構化特徵摘要表：

| 缺陷模式     | 晶圓視覺特徵                            | MES/NPI 關鍵篩選主鍵 (資料庫欄位)                 | 底層核心物理機制                                                        | 系統自動化防禦行動 (Action Item)                                         |
| :----------- | :-------------------------------------- | :------------------------------------------------ | :---------------------------------------------------------------------- | :----------------------------------------------------------------------- |
| 6.1 疊加偏移 | 環形缺陷 (Edge Ring)                    | OVERLAY_X/Y > Spec、Alignment_Warning             | 晶圓熱應力翹曲 (Warpage)、曝光機載台邊緣 Particle 污染。                | 自動發出 WARNING 警報，提示硬體團隊體檢載台平整度。                      |
| 6.2 關鍵尺寸 | 直線型不良 (Line)、積雨雲群聚 (Cluster) | CD_LINEWIDTH 系統性超規、Dose Error Log           | Scanner 掃描機械軌跡瞬間震動、局部表面超出了焦深 (DOF) 容許範圍。       | 良率預測低於 LCL 時自動下發 HOLD_LOT 熔斷指令 攔截產品。                 |
| 6.3 蝕刻偏差 | 同心圓分佈、隨機零星散佈 (Random)       | Thickness Deviation 超規、RF Reflected Power 抖動 | 反應腔壓力或 RF 功率偏離導致電漿不均；腔壁剝落產生 Micro-masking 遮蔽。 | 隨機缺陷觸發 AutoEncoder 計算重建誤差；自動將異常 Tool ID 移出派工名單。 |
| 6.4 設備老化 | 缺陷率隨時間緩慢爬升                    | Touchdown Count 攀升、Contact Resistance 線性變大 | 測試探針卡（Probe Card）氧化、磨損，導致高頻電性量測訊號失真。          | 預測性維護 (PdM)：監控滾動良率斜率，自動預警提示安排保養 (PM)。          |
| 6.5 操作錯誤 | 批量性非對稱異常                        | Log 出現 Manual_Override、整批特定區域集體失敗    | 操作員未按 SOP 手動更改設定值、或吸腳未卡緊造成物理刮傷。               | 觸發 HUMAN_RISK 標記，自動追溯並凍結受影響的整批晶圓。                   |

- 總結：在我的數據管道中，第六章的領域知識不僅是靜態筆記，更是第七章主程式判讀的規則庫。我在 6.5 操作錯誤與摘要 中，將所有製程缺陷（微影、蝕刻、老化、人為疏失）進行了高密度的橫向對齊。這樣做的好處是，當第七章的 main.py 讀取資料庫時，可以根據這張大摘要表定義的『篩選主鍵』（如 OVERLAY_X、CD_LINEWIDTH、RF Power），自動辨識出當前的產線異常是屬於 6.2 的 Scanner 掃描震動，還是 6.5 的人為手動超馳，並對應觸發自動熔斷（Hold）或預測性維護（PdM）。這能讓自動化系統具備真正的半導體專家思維。
