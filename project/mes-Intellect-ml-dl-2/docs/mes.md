## MES 簡述

- MES 日誌，用於記錄整批產品（如一籃共 25 片）進出機台的時間、機台參數、化學液濃度或警報紀錄等。

## 常見兩種檔案型式

|       特性        | log 格式 (含 \|)                               | JSON 格式                                        |
| :---------------: | ---------------------------------------------- | ------------------------------------------------ |
|     主要位置      | 機台本機、資料夾 Raw Data、資料庫批次匯出。    | IT 系統 API、雲端平台、網頁前端戰情室。          |
|     處理人員      | 製程/設備/CIM工程師、資料工程師。              | IT 軟體工程師、網頁工程師。                      |
|     最大優點      | 檔案體積極小、讀寫速度極快、適合巨量歷史資料。 | 結構彈性（可巢狀嵌套）、好讀、現代軟體支援度高。 |
| 專用 VS Code 套件 | Rainbow CSV、Edit CSV                          | LogLens、JSON Crack                              |

- 此專案使用 .log 格式，使用分隔符（如 |）來節省系統寫入 Log 的 I/O 負擔。
